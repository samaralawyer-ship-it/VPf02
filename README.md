# Telegram-бот с контекстом диалога на DeepSeek API

Учебный проект по уроку **VPf02 «Подключение AI API к проекту»**.
Бот ведёт диалог с языковой моделью, помнит контекст каждого пользователя
в оперативной памяти и позволяет менять параметры генерации.

## Стек

- Python 3.11+
- `aiogram` 3.x — Telegram-бот
- `httpx` — HTTP-запросы к API
- `python-dotenv` — секреты из `.env`
- Модель: `deepseek-flash` (DeepSeek-V4.1-Flash), адрес `https://api.deepseek.com`

## Структура

```
VPf02/
├── bot.py               хендлеры aiogram, команды, отправка в LLM
├── config.py            чтение .env, значения по умолчанию
├── api_client.py        клиент /chat/completions, повторы, разбор usage
├── context_manager.py   истории и параметры пользователей в памяти
├── requirements.txt
├── .env.example         шаблон настроек (копируется в .env)
└── README.md
```

## Запуск

```bash
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

copy .env.example .env      # затем вписать BOT_TOKEN и DEEPSEEK_API_KEY
python bot.py
```

Токен бота берётся у `@BotFather`, ключ API — в кабинете `platform.deepseek.com`.

## Команды бота

| Команда | Что делает |
|---|---|
| `/start` | приветствие и список команд |
| `/help` | как пользоваться |
| `/reset` | очистить контекст (то же — фраза «очистить контекст») |
| `/settings` | текущие параметры и размер истории |
| `/temperature 0.3` | креативность, диапазон 0..2 |
| `/tokens 800` | предел длины ответа, диапазон 64..8192 |
| `/usage` | токены последнего ответа |

## Параметры

| Параметр | Диапазон | По умолчанию |
|---|---|---|
| `temperature` | 0.0 – 2.0 | 0.7 |
| `max_tokens` | 64 – 8192 | 512 |
| `HISTORY_TOKEN_LIMIT` | — | 6000 токенов истории |

История обрезается по бюджету: пока сумма больше лимита, удаляется самая старая
пара «вопрос — ответ». Системная инструкция не удаляется.

Важно: режим размышлений модели по умолчанию **выключен** (`THINKING_MODE=disabled`),
потому что в нём `temperature` не влияет на ответ, а запросы стоят дороже.

## Эксперименты (таблица для отчёта)

Заполняется вручную по прогонам в Telegram. Скриншоты Usage — в кабинете DeepSeek.

| Модель | temperature | max_tokens | Прогон | Эффект (сжатость / креатив) | Токены | Стоимость |
|---|---|---|---|---|---|---|
| deepseek-flash | 0.2 | 200 | 1 | | | |
| deepseek-flash | 0.7 | 200 | 2 | | | |
| deepseek-flash | 1.5 | 200 | 3 | | | |
| deepseek-flash | 0.7 | 1000 | 4 | | | |

Стоимость для `deepseek-flash` (за 1M токенов, вход без кеша / выход): $0.15–0.30 / $0.60–1.20
(разница — дневной и ночной тариф). Формула:

```
стоимость = prompt_tokens / 1e6 * цена_входа + completion_tokens / 1e6 * цена_выхода
```

Токены берите из `/usage` или из лога `bot.log`.

## Ограничения

- История живёт в памяти процесса: после перезапуска бота контекст теряется.
- Один пользователь — одна история, без ветвлений диалога.
- Нет передачи файлов, изображений и голоса.
- Нет базы данных и админ-панели.
